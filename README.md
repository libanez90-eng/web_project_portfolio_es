# Portafolio

Portafolio Personal

Descripción del proyecto

Este proyecto consiste en el desarrollo de un portafolio web personal y responsivo, realizado como parte del Sprint 4 del programa de Desarrollo Web de TripleTen.

El sitio presenta el perfil profesional de una desarrolladora web, sus habilidades técnicas, proyectos destacados y medios de contacto.

La página está diseñada para adaptarse a diferentes tamaños de pantalla, siguiendo las especificaciones de Figma para escritorio (1440 px), tablet (768 px) y móvil (320 px).

Tecnologías y técnicas utilizadas

HTML5: estructura semántica del contenido.

CSS3: estilos, tipografía y diseño visual.

Flexbox y CSS Grid: distribución y alineación de elementos.

Media Queries: adaptación del diseño a diferentes resoluciones.

Metodología BEM: organización de las clases CSS.

Figma: referencia para implementar el diseño.

Chrome DevTools y PerfectPixel: comprobación de dimensiones, posiciones y diseño responsivo.

Funcionalidades

Presentación del perfil profesional.

Visualización de habilidades y herramientas.

Tarjetas de proyectos destacados.

Enlaces de contacto y redes sociales.

Imagen de perfil adaptada a dispositivos móviles.

Efectos visuales y transiciones al pasar el cursor.
